PK is a peaking filter. LSC and HSC are shelves where Q sets the transition (alpha = sin ω / 2Q, the Equalizer APO convention), so the gain at Fc is half the shelf gain. Limits: gain ±60 dB, Q 0.01–100, Fc 1–96 000 Hz and below half the sample rate. Values outside the limits are refused, never clamped.

Import or export AutoEQ text

    Accepted lines: Preamp, Filter N: ON|OFF PK|LSC|HSC Fc … Hz Gain … dB Q …, blank lines, and comments starting with #, ; or //. If any line is wrong, nothing is applied and the current setup stays as it is. GraphicEQ text is a different format and is not supported yet.
